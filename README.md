# React Study

React 학습 기록입니다.

## 학습 방식

각 강의는 아래 사이클로 진행합니다.

1. **개념 학습**: 강의 주제의 핵심 개념 정리
2. **숙제 구현**: 요구사항에 맞춰 직접 코드 작성
3. **코드 리뷰**: 작성한 코드에 대한 피드백 수령
4. **피드백 반영**: 리뷰 내용을 이해하고 코드 개선

첫 제출과 피드백 반영을 별도 커밋으로 남겨, 개선 과정을 커밋 히스토리에서 확인할 수 있습니다.

## 실행 방법

각 강의 폴더에서 실행합니다.

```bash
cd 01-components
npm install
npm run dev
```

## 커밋 컨벤션

[Conventional Commits](https://www.conventionalcommits.org/) 형식을 따릅니다.

| 타입 | 용도 |
|---|---|
| `feat` | 숙제 구현, 기능 추가 |
| `refactor` | 피드백 반영, 코드 개선 |
| `fix` | 버그 수정 |
| `docs` | 문서 작성 및 수정 |

예시: `refactor(01): 태그 선택자를 className 기반으로 변경`
